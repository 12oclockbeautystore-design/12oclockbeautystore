# 12 O'Clock Beauty - Ultra-Luxury Cosmetics E-Commerce Store

A modern, elegant online storefront for premium beauty products.

## Features

- Beautiful responsive design
- Product showcase
- Admin dashboard
- Contact form
- Modern UI with gradient styling

## Files

- `index.html` - Main storefront
- `styles.css` - Storefront styles
- `script.js` - Storefront functionality
- `dashboard.html` - Admin dashboard
- `dashboard.css` - Dashboard styles
- `dashboard.js` - Dashboard functionality

## Deployment

This site is ready to deploy on Netlify.

1. Push to GitHub
2. Connect to Netlify
3. Deploy!
